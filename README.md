# SHOTEN GTE 自定义固件

Experimental firmware extension for the SHOTEN GTE Contax G → Sony E autofocus adapter.

当前版本：**0.55 / `v0.55-exp`，实验预发布**。机身版本界面预计显示 `.55`。本项目基于官方 **Ver.04** 固件增加 ARM 扩展，并保留原版硬件初始化、校准和主要马达控制流程。它不是厂商发布或认证的固件，也不是天工 EA9 固件的直接移植。

这份发布使用现有 `.55` 镜像，整理文档时没有改动固件字节。当前版本获得使用者的可用性反馈；实机反馈主要来自 **SHOTEN GTE V01.02 + Sony A7 IV / ILCE-7M4 6.02 + Planar G35/2**。六个镜头预设都已加入并通过软件检查，其他镜头尚缺实机反馈。

> **刷机风险与责任声明**：本固件为未经厂商认证的实验版本。刷入和使用可能造成转接环无法启动、对焦异常，或影响相机、镜头及拍摄数据。请在核对型号和文件、保存可用固件后自行决定是否刷入，并自行承担由此产生的风险。在适用法律允许的范围内，本项目作者及发布者不对因刷入或使用本固件造成的设备损坏、数据丢失或其他损失承担责任；不保证固件适用于所有设备，也不保证故障后能够恢复。

## 这版做了什么

- 加入六款兼容镜头的独立资料、光学文件传输、原生 E 卡口身份与位置反馈，尝试改善原版受限的 AF 交互。**尚未验证全画面各位置的合焦覆盖和准确率。**
- 继承 0.52 的马达启动、真实停机、换向和当前位置回报修复，针对近距离 AF-C 合焦后反复拉动的问题。
- 继承 0.54 的大行程驱动策略：在满足方向、距离和边界条件时，输出上限从原版 5040 提高到 7056；接近目标或机械边界时渐退到原版上限。**上限 +40% 不等于实际对焦速度 +40%。**
- 0.55 新增稳定到位完成判定，减少一部分已经到达目标后的等待；没有继续加大峰值驱动。
- 没有加入松开快门后两秒自动回无穷远。显式停止、开关机归位和原版保护流程仍保留。

基本视频对焦曾在 0.53 的上述机身与 G35 组合上获得用户反馈，包括切换目标及录制中缓慢合焦。后续视频功能开发已暂停；本版没有新增视频专用指令，共用运动结束时序仍可能影响视频表现。

当前固件：[GTE_ALL_EXP055.bin](release/v0.55-exp/GTE_ALL_EXP055.bin) · [发布说明](release/v0.55-exp/RELEASE_NOTES.md)

下载 GitHub 仓库里的 BIN 时，请使用文件页面的 **Download raw file**；不要把网页另存为 `.bin`。也可以下载完整发布包后解压。

## 适用范围与限制

| 项目 | 当前状态 |
| --- | --- |
| 接环 | SHOTEN GTE；已知实机反馈硬件 V01.02 |
| 原版基线 | 仅接受固定 SHA-256 的官方 Ver.04，不能套用其他型号或原版布局 |
| 机身反馈 | Sony A7 IV / ILCE-7M4，机身固件 6.02 |
| 主要使用模式 | AF-C；未实现 AF-S 所需的完整 Scan 流程 |
| 镜头预设 | 六个，见下表；加入资料不代表六款均已实测 |
| 变焦镜头 | 35–70mm 仅按 70mm 端预设，不检测变焦位置 |
| 全画面 AF | 目标之一；尚无覆盖全画面的网格实测结论 |
| 性能 | 有主观提速反馈；没有实测提升百分比、电流或温升数据 |

实验固件会改变马达驱动和完成判定。刷入前保存原版及当前可用版本；出现持续抽动、撞限位、异常发热或无法正常关机时，停止使用。仅在接环仍能进入 USB 更新模式时，才可尝试原流程回刷，不能保证任何异常都可通过 USB 恢复。

## 镜头选择

登记值是机身设置界面的选择代码，**不是拍摄时必须使用的实体光圈**。

| 登记值 | 镜头 | 预设焦距 | 实机反馈 |
| --- | --- | --- | --- |
| F2.8 | Biogon G21mm f/2.8 | 21mm | 待补充 |
| F4 | Biogon G28mm f/2.8 | 28mm | 待补充 |
| F5.6 | Planar G35mm f/2 | 35mm | 主要反馈组合 |
| F8 | Planar G45mm f/2 | 45mm | 待补充 |
| F11 | Sonnar G90mm f/2.8 | 90mm | 待补充 |
| F16 | Vario-Sonnar G35–70mm f/3.5–5.6 | 70mm 端 | 待补充 |

Hologon G16 不在 GTE 的机械兼容范围内。35–70mm 的 70mm 端限制也见[厂商产品说明](https://www.stkb.jp/shopdetail/000000001523/)。

登记步骤：

1. 把机身设为 A 或 M 档，然后关机。
2. 按住**接环上的功能按钮**开机；出现 MF 后松开按钮。
3. 用机身拨轮选表中登记值，例如 G35 选 **F5.6**。
4. 拍一张照片，关机再开机。检查照片 EXIF 是否为预期焦距。
5. 拍摄时再按需要调整镜头的实体光圈环。若 G35 已正确登记且 EXIF 为 35mm，不必为了升级重复登记。

## USB 升级

1. 关闭相机，将接环从机身取下。保存接环 USB 盘上的 `README.TXT`，确认硬件版本及原有固件版本。
2. 用支持数据传输的 **Micro-B USB 线**将接环单独连接电脑，等待出现 **DOWNLOAD** 盘。
3. 只把解压后的 **`GTE_ALL_EXP055.bin`** 复制进去。不要复制 ZIP、源代码、文档或多个版本的 BIN。
4. 至少等待 **20 秒**，在系统里安全弹出 DOWNLOAD，再拔线。
5. 重新连接 USB，查看 `README.TXT` 的 Software Version；安全弹出后装回机身，再检查版本显示。只完成复制不能证明已升级成功。

传输流程依据[厂商升级说明 PDF](https://stkb.co.jp/file/GTE_dl_manual.pdf)。机身通常显示 `.55`；USB README 的实际版本字段也应核对。若仍显示旧版，先检查数据线、实际复制的文件和等待时间，不要反复拔插正在写入的设备。

回退时使用相同流程，每次只复制一个已保存且适配该接环的 BIN。官方 `.04` 从[厂商支持页](https://stkb.co.jp/support.html#gte)取得，构建脚本会核对其固定哈希。本仓库不附原版镜像。**刷机失败时请按[回刷官方 Ver.04 教程](docs/RECOVERY.md)分情况处理。**旧的 `GTE_FLASH_051.sh` 内嵌的是 0.51，不能用于安装本版。

## 建议的首次检查

先用熟悉的镜头和正常光线测试。G35 可先选 AF-C、固定实体光圈 f/5.6，对同一组近远细节目标反复对焦；保持半按或 AF-ON，检查清晰度及是否反复抽动，再松开确认仍能停止并再次响应。用同样条件比较版本，记录多次结果；不要用驱动参数或单次体感推算速度百分比。

更换镜头后重新登记相应预设，并检查中心、边缘和近远距离。提交反馈时可使用 [Issue 模板](.github/ISSUE_TEMPLATE/feedback.md)，提供机身、固件、镜头、对焦模式和复现步骤，无需提供设备序列号或个人信息。

## 构建与验证

源码、生成镜头资料的脚本和 CPU 仿真验证都在仓库中。[构建说明](docs/BUILD.md)提供完整复现命令；[验证边界](docs/VALIDATION.md)区分用户反馈、CPU 检查与尚未验证的项目。

本版通过 **8,208 项 CPU 仿真检查**，并能重新构建得到同一 BIN 哈希。仿真不包含实际镜头的摩擦、惯性、温度、电流或机身 AF 算法，不能替代实机验证。
