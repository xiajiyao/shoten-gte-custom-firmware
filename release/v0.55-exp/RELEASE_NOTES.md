# GTE 0.55 — 稳定到位响应实验预发布

发布标识：`v0.55-exp`。日期：2026-11-26。机身版本预计显示 `.55`。

本次发布冻结当前可用的 0.55 镜像，并补齐源码、中文使用说明和验证记录。没有因整理仓库而重新调高驱动参数或改变镜像字节。

## 主要变化

相对 0.54，新增稳定到位完成判定：在正常 AF 运动、位置接近目标且持续稳定的条件下，经过分开的多次观测后调用原版停机，减少一部分到位等待。维持 0.54 的驱动上限、渐退条件和原版保护。没有两秒自动回无穷远，没有新增视频专用功能。

累积包含六个镜头预设、协议与位置回报补充、0.52 真实停机/启动/换向修复，以及大行程有条件增强。完整内容见仓库 README 和 CHANGELOG。

## 兼容与验证

主要实机反馈来自 **GTE V01.02 + A7 IV 6.02 + G35/2，AF-C**。使用者认为当前版本可接受。另五个镜头预设已加入并通过软件检查，尚缺实机反馈；35–70mm 仅按 70mm 端使用。全画面 AF 准确率、AF-S、其他机身和全部录像场景没有验证结论。

重建 BIN 与当前镜像哈希一致，8208 项 CPU 仿真检查通过。+40% 指输出上限，不是实测 AF 提速。名义 12ms 是到位稳定窗口，不是总对焦时间。电流、温升和真实机械性能未测量。

## 安装

接环单独用 Micro-B 数据线连接电脑，将 **GTE_ALL_EXP055.bin** 复制到 DOWNLOAD 盘。只复制一个 BIN，至少等待 20 秒，安全弹出再拔线。重新连接读取 `README.TXT`，再装回机身核对版本。详细登记和回退说明见随附说明或仓库 README。

刷机异常时按[回刷官方 Ver.04 教程](../../docs/RECOVERY.md)先判断 DOWNLOAD 是否仍可用；不能进入更新模式时，不要格式化磁盘或反复尝试复制固件。

登记值不是拍摄时必须使用的实体光圈。
