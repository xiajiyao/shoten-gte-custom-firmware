# 历史扩展源码

这些源码快照用于编译仿真回归所需的精确对照镜像，不是推荐刷入版本。尤其 0.51 存在已知运动控制缺陷。

每个目录保留 `patch.c`、`entries.S`、`patch.ld` 和 `build.py`，镜头资料由构建脚本生成。公开整理时只统一了构建脚本的编译器选择顺序：优先使用可用的固定版本 Python ziglang 包。控制源码未修改，并以历史镜像固定 SHA-256 核对结果。

运行 `python3 tools/prepare_baselines.py vendor/Ver.04.bin` 即可生成验证对照。脚本不连接硬件；不要把生成目录当作面向使用者的固件下载列表。
