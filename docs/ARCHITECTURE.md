# 实现概览

这是一份固定版本二进制扩展：原版镜像 SHA-256 和入口字节匹配后才构建。不是完整替换厂商固件，也不适用于 EA9。

## 布局

| 区域/入口 | 地址 | 作用 |
| --- | --- | --- |
| 原版应用 | `0x08020000` | 保留硬件初始化、校准读取、原版 PID 和保护等主体 |
| 自定义扩展 | `0x08024000` | 编译的 Thumb Cortex-M4 扩展，当前 16072 字节 |
| 扩展预留 RAM | `0x20001000`–`0x200017ff` | 大回复缓冲与上下文 |
| 原版命令分发 hook | `0x08020b64` | 校验与受支持命令桥接 |
| 原版回复准备 hook | `0x080221b4` | 身份、光学文件、位置等回复 |
| 原版输出限幅 hook | `0x08021544` | 条件满足时提高输出上限 |
| 原版马达轮询 hook | `0x08021c94` | 稳定到位判定，再执行原入口语义 |
| 原版停机函数 | `0x08022088` | 真实制动输出和 PID 历史清理 |

原版 16 字节 USB 文件头保留；文件偏移与 MCU 地址之间需计入该头。Reset 向量先转入扩展，清零预留 RAM 后回到原版复位流程。除 Reset 外其余中断向量保持原样。构建检查总应用不超过原版扇区范围，不修改接环现有 USB 引导更新程序。

硬件内存布局由该固件反汇编推断；只有 V01.02 接环的用户反馈，不将 MCU 推断当作芯片实物鉴定。

## 协议与镜头资料

补充原生身份、六个预设和 `0x3A` / `0x3B` / `0x3D` 光学文件回复。每份 LF 内容 2168 字节，传输包另有协议头；大型回复使用独立缓冲，完成后恢复原版短回复地址。

Move `0x1D` 桥接绝对、距离、相对与离焦类目标，Stop `0x1C` 调用原版停机。当前位置回报同时更新原生 NOW 与既有预测字段，但没有实现真正的速度预测器。未新增完整 Scan `0x1F` 或连续 Drive `0x3C`，能力声明也不将它们作为已实现功能宣传。

镜头选择读取原版持久化登记数据，空记录沿用 G45 默认预设。切换镜头需按 README 登记；不能自动识别镜头或读取 35–70mm 的变焦环。

## 输出限幅与稳定完成

只有正常会话、马达运行、有效位置及朝向目标的驱动请求可增强。距目标和距边界任一不足 32 个计数时不增强，32–64 个计数渐入；两项都至少 64 时才能用完整上限 7056。反向制动请求维持原版上限。原版 PID 的误差符号是 CURRENT − TARGET，不能直接照几何方向写增强条件。

0.55 的新完成路径要求误差 ≤3 个计数、窗口内相对起点漂移 ≤1 个计数、观测间隔至少 100 个节拍、间隔大于 400 则重置、至少 8 次观测且总窗口 ≥1200 节拍。目标更换、位置离开容差或异常间隔也重置。

满足条件后调用原版停机，清除运行状态，由原版后续通信流程发送完成事件。显式 Stop 优先；该路径不用于开关机归位，也没有自动回无穷远计时器。判断对象是运动到达目标，不是光学清晰度。
