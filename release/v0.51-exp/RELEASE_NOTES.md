# GTE 0.51 — 首次六镜头预设（存在已知缺陷）

**实验历史版本**，基于 SHOTEN GTE 官方 Ver.04；不是厂商固件。此 Release 与其他历史版本都从公开整理后的仓库快照建立标签，历史开发时的独立提交未保留；版本差异以相应源码和固件哈希为准。

新增六个 Contax G 镜头预设、光学文件传输、原生身份与位置回报的第一版。使用者确认机身显示 .51。随后发现近距离 AF-C 合焦后反复拉动、松开快门后回无穷远；已复现原版真实停机未调用、启动状态和当前位置回报的问题。**存在已知马达控制缺陷，不建议刷入；仅供历史回归对照。**

主要反馈来自 GTE V01.02、Sony A7 IV 6.02、G35/2。其他镜头及全画面 AF 准确率尚缺实机验证。
