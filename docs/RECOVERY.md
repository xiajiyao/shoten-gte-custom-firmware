# 刷机失败后回刷官方 Ver.04

此教程适用于 **SHOTEN GTE** 接环，前提是接环单独连接电脑时仍能稳定出现 **DOWNLOAD** 盘。它是使用厂商正常 USB 更新流程回刷官方固件的步骤，**不是引导程序或硬件损坏后的通用救砖方法**。厂商说明没有承诺该型号在任何故障状态下都能降级或恢复。

如果更新过程中刚复制完文件、盘符短暂变化，先按厂商要求等待至少 20 秒；不要在写入期间拔线。若出现异常马达持续运动、撞限位或发热，关闭相机、取下接环，暂停拍摄与进一步对焦测试。

## 先确认属于哪种情况

| 现象 | 下一步 |
| --- | --- |
| 相机显示异常，但接环单独连接电脑仍出现 DOWNLOAD | 可按下文尝试回刷 Ver.04 |
| DOWNLOAD 出现，但原版 BIN 复制后版本仍未改变 | 检查下载文件和数据线，按下文核对一次；不要连续盲目重刷 |
| 电脑不出现 DOWNLOAD，或磁盘连接反复中断 | 换一根确定能传数据的 Micro-B 线和电脑 USB 口再检查；仍不识别时停止自行刷写，联系厂商/销售方 |
| 电脑要求“初始化/格式化磁盘” | **不要格式化**。GTE 的官方说明没有将格式化列为恢复步骤；停止并联系厂商/销售方 |

## 准备官方文件

1. 从[焦点工房 SHOTEN GTE 支持页](https://stkb.co.jp/support.html#gte)下载该型号 **Ver.04**。厂商的[下载入口](https://stkb.co.jp/file/fwdl.html)可能要求先阅读并接受其使用条款。文件应名为 `Ver.04.bin`；不要选 GXTZ、NZ-E、TECHART EA9 或其他接环的固件。
2. 在电脑上确认下载得到的是 BIN，而不是网页或 ZIP。已核对的官方 Ver.04 文件为 **13,956 字节**，SHA-256：

   ```text
   28c30d003a8b2a399cf7c019dfc400dcae751c24dc17bc653f325244a3310c09
   ```

   macOS 终端示例：

   ```bash
   shasum -a 256 ~/Downloads/Ver.04.bin
   ```

   若大小或哈希不符，停止操作并重新从官方页面取得正确文件。**不要使用本仓库的 0.51、0.54 或 0.55 镜像来代替原厂 Ver.04。**

## 回刷步骤（DOWNLOAD 仍可用）

1. 关闭相机，把接环从机身和镜头上取下。用支持**数据传输**的 Micro-B 线单独连接电脑，确认出现 `DOWNLOAD` 盘。若能打开盘内的 `README.TXT`，先保存一份并记下当前版本。
2. 只把下载并校验过的 **`Ver.04.bin`** 复制到 `DOWNLOAD`。不要把 ZIP、说明文档或多个 BIN 一起复制进去，也不要运行旧的 `GTE_FLASH_051.sh`。
3. 复制完成后至少等待 **20 秒**；在操作系统中**安全弹出** `DOWNLOAD`，再拔下 USB。复制完成的提示本身不代表固件已经安装完成。
4. 重新用 USB 连接接环，打开 `README.TXT` 检查 Software Version 是否显示 **V00.04 / Ver.04**，然后再次安全弹出。若盘内版本未变或内容异常，停止反复刷写。
5. 关闭相机后装回接环与镜头，在机身版本显示中确认 `.04`。再检查镜头登记值和 EXIF；如需重新登记 G35，按仓库 README 的方法选择 **F5.6**（这只是登记代码，并非实体光圈必须设为 f/5.6）。

厂商的[SHOTEN GTE USB 更新说明](https://stkb.co.jp/file/GTE_dl_manual.pdf)明确列出数据线、复制 BIN、等待 20 秒、安全弹出以及通过 `README.TXT` 或机身版本菜单检查结果。这套流程是**有条件的回刷尝试**：若接环不能进入 USB 更新模式，普通复制文件的方法便无法执行；本项目没有经过验证的拆机、短接、SWD 或其他硬件救砖步骤。

若上述核对后仍不能识别或无法恢复，请记录 GTE 硬件版本、当前显示、数据线/电脑、复制时的报错，并通过[焦点工房支持页](https://stkb.co.jp/support.html#gte)联系厂商或销售方。不要把序列号、个人联系方式或设备内部照片公开发到 Issue。厂商[下载条款](https://stkb.co.jp/file/fwdl.html)提示更新失败及降级存在限制；请以对方对你这只接环的诊断为准。
